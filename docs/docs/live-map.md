# Live map

The **Live Map** answers one question: *where is Starlink right now?*

## What you'll see

- The **current positions** of the lead satellites of the chains being tracked, each shown as a satellite marker with its name.
- **Colored tracks** showing the path each satellite is following.
- A marker for **your location**, so you can see how the passes relate to where you're watching from.
- Everything **updates continuously** - satellite positions refresh every second and the tracks are redrawn every few minutes.

## Important caveat

The satellites move at an unbelievable speed - they travel nearly **500 km/300 miles EVERY MINUTE**. Because they're so high up in the sky, you can still see them from very far away, which means the map can make a pass look like it's happening somewhere else entirely.

So don't worry about the Live Map - **the Results page is what you should believe**. Use the map to get a feel for where the satellites are, and use the timings to know when to look up.
